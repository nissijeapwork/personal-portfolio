# Nissi Jea C. Paglinawan — Portfolio

Responsive portfolio website with a mobile hamburger navigation, animated dark tech aesthetic, responsive experience/education layouts, and project cards optimized for small screens.

## Responsive fixes
- Experience and education headings now occupy the full content width on smaller screens.
- Company/school location is placed on its own line below the heading.
- Long headings and organization names wrap safely without horizontal overflow.
- Project technology chips now flow below the project description instead of using absolute positioning on mobile.
- Project cards automatically grow with their content across mobile, tablet, and desktop widths.
- Smaller breakpoints adjust typography and spacing for narrow devices.

## Responsive coverage
The current build includes responsive layouts for desktop, small laptops, iPad/tablet portrait and landscape, mobile phones, and very narrow screens. Project technology chips remain in normal document flow on tablet/mobile sizes so they cannot overlap long project descriptions. Experience and education role/location metadata also stack cleanly on smaller screens.
